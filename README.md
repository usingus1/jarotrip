# 일본 마운자로 병원 가이드

일본에서 한국어로 마운자로 상담·처방 안내를 하는 병원의 용량별 가격(1개월 4펜 / 3개월 12펜)과 예약 상황을 보여주는 정적 웹페이지입니다.

- `index.html` — 화면 (필터·정렬·검색·변경 기록)
- `data.json` — 병원 데이터. 매일 아침(한국 시간 07:17) 예약 작업이 원본 시트를 갱신한 뒤 이 파일을 덮어써 커밋합니다.
- `manifest.webmanifest`, `sw.js`, `icons/` — 홈 화면 추가(앱 아이콘)와 오프라인 보기

## data.json 형식

```json
{
  "updatedAt": "YYYY-MM-DD",
  "header": ["병원명", "도시", "1개월 2.5mg", "...", "비고"],
  "rows": [["병원명", "도시", 8000, "..."]],
  "log": [["날짜", "병원명", "구분", "변경 내용", "출처"]]
}
```

화면은 `header`의 열 이름으로 값을 찾으므로 열 순서가 바뀌어도 동작합니다.

## stays.json 형식 (여행 짜기 · 근처 최저가 숙소)

```json
{
  "updatedAt": "YYYY-MM-DD",
  "header": ["조회일", "도시", "지역", "숙소명", "1박 최저가(원)", "역·도보", "트립닷컴 호텔ID", "출처", "비고"],
  "rows": [["2026-11-25", "도쿄", "신주쿠", "숙소 이름", 55000, "신주쿠역 도보 5분", "1234567", "https://kr.trip.com/hotels/...", "메모"]]
}
```

- `도시`는 병원 데이터의 도시 이름(도쿄·오사카·후쿠오카·나고야·삿포로·교토·히로시마·가고시마)과 같게 씁니다.
- `지역`은 화면이 병원 이름·주소에서 찾는 동네 이름(신주쿠, 긴자, 시부야, 고탄다, 신바시, 이치가야, 우에노, 신사이바시, 난바, 텐진, 나카스, 하카타, 사카에, 메이에키, 스스키노 등)과 같게 쓰면 병원과 같은 동네 숙소가 먼저 골라집니다. 같은 동네가 없으면 이웃 동네, 그다음 도시 전체에서 가장 싼 곳을 고릅니다.
- **트립닷컴(제휴처) 자료만 씁니다.** `출처`가 trip.com 주소가 아닌 줄은 화면에서 무시합니다. `트립닷컴 호텔ID`가 있으면 "이 숙소 보기" 버튼이 그 숙소 상세 페이지를, 없으면 숙소 이름 검색을 고른 날짜·인원으로 엽니다. 두 경우 모두 제휴 ID(Allianceid·SID)가 붙습니다.
- 여행 짜기의 숙박비 = 1박 최저가 × 박수 × 객실 수(2명당 1실) ÷ 인원(1인 부담분). 날짜와 무관한 참고값입니다.

## 커뮤니티 (자유게시판 · 불편사항)

글은 Supabase(무료 요금제로 충분)에 저장합니다. 처음 한 번만 설정하면 됩니다.

1. https://supabase.com 에서 새 프로젝트를 만듭니다(지역: Northeast Asia (Seoul) 추천).
2. 왼쪽 **SQL Editor** → `supabase/community.sql` 내용을 전부 붙여 넣고 **Run**.
3. **Project Settings → API**에서 `Project URL`과 `anon` `public` 키를 복사해 `index.html`의 `const SB={url:'',key:''}`에 넣고 커밋합니다. (anon 키는 공개용이라 페이지에 넣어도 됩니다. `service_role` 키는 절대 넣지 마세요.)

- **자유게시판**: 누구나 읽고 씁니다. 글쓴이는 쓸 때 정한 비밀번호로 지울 수 있고, 운영자는 대시보드 **Table Editor → posts**에서 아무 글이나 지울 수 있습니다.
- **불편사항**: 사이트에서는 보내기만 되고 읽기 권한이 없어 **운영자만** 대시보드 **Table Editor → feedback**에서 봅니다.
- 설정 전에는 커뮤니티 탭에 "준비하고 있어요"가 뜨고 버튼이 꺼져 있습니다.

## 운영자 현황판 (live.html)

`/live.html`을 열면 1분마다 갱신되는 현황이 보입니다(검색 노출 안 됨).

- **지금 접속 중**: 사이트가 열려 있는 동안 30초마다 보내는 신호로, 최근 90초 안에 보고 있던 인원과 화면별 인원을 보여 줍니다. 처음 한 번 Supabase **SQL Editor**에서 `supabase/live.sql`을 실행해야 숫자가 나옵니다.
- **일일 방문자**: 오늘·어제·7일·30일 방문자(GoatCounter, 하루 한 명으로 셈).
- **결제 페이지로 이어진 횟수**: 트립닷컴 항공권·숙소 버튼을 누른 횟수와 사람 수, 방문자 대비 비율.
- **실제 결제 건수**는 결제가 트립닷컴에서 일어나 사이트에서 셀 수 없습니다. 트립닷컴 제휴 파트너 화면의 주문 보고서에서 보고, `trip_sub1`(jarotrip-flight, jarotrip-stay 등)으로 어느 버튼에서 왔는지 나눠 봅니다.
