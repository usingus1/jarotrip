# 일본 마운자로 병원 가이드

일본에서 한국어로 마운자로 상담·처방 안내를 하는 병원의 용량별 가격(1개월 4펜 / 3개월 12펜)과 예약 상황을 보여주는 정적 웹페이지입니다.

- `index.html` — 화면 (필터·정렬·검색·변경 기록)
- `data.json` — 병원 데이터. 매일 아침(한국 시간 07:17) 예약 작업이 원본 시트를 갱신한 뒤 이 파일을 덮어써 커밋합니다.
- `manifest.webmanifest`, `sw.js`, `icons/` — 홈 화면 추가(앱 아이콘)와 오프라인 보기

## data.json 형식

```json
{
  "updatedAt": "YYYY-MM-DD",
  "header": ["병원명", "도시", "1개월 2.5mg", "...", "비고"],
  "rows": [["병원명", "도시", 8000, "..."]],
  "log": [["날짜", "병원명", "구분", "변경 내용", "출처"]]
}
```

화면은 `header`의 열 이름으로 값을 찾으므로 열 순서가 바뀌어도 동작합니다.

## stays.json 형식 (여행 짜기 · 근처 최저가 숙소)

```json
{
  "updatedAt": "YYYY-MM-DD",
  "header": ["조회일", "도시", "지역", "숙소명", "1박 최저가(원)", "역·도보", "출처", "비고"],
  "rows": [["2026-11-25", "도쿄", "신주쿠", "숙소 이름", 55000, "신주쿠역 도보 5분", "https://...", "메모"]]
}
```

- `도시`는 병원 데이터의 도시 이름(도쿄·오사카·후쿠오카·나고야·삿포로·교토·히로시마·가고시마)과 같게 씁니다.
- `지역`은 화면이 병원 이름·주소에서 찾는 동네 이름(신주쿠, 긴자, 시부야, 고탄다, 신바시, 이치가야, 우에노, 신사이바시, 난바, 텐진, 나카스, 하카타, 사카에, 메이에키, 스스키노 등)과 같게 쓰면 병원과 같은 동네 숙소가 먼저 골라집니다. 같은 동네가 없으면 이웃 동네, 그다음 도시 전체에서 가장 싼 곳을 고릅니다.
- 여행 짜기의 숙박비 = 1박 최저가 × 박수 × 객실 수(2명당 1실) ÷ 인원(1인 부담분). 날짜와 무관한 참고값입니다.

## 안내

정보 제공용이며, 처방 여부와 용량은 진찰한 의사가 판단합니다. 가격·예약 상황은 수시로 바뀌니 방문 전 병원에 직접 확인하세요.
